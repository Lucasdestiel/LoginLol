🎮 League of Legends Login UI

Uma interface de login inspirada no universo de League of Legends, com foco em experiência visual, identidade e microinterações.

Projeto desenvolvido para explorar conceitos de UI/UX design aplicados ao front-end.

🎯 Foco do Projeto

Mais do que funcionalidade, este projeto foi focado em:

Experiência do usuário (UX)
Interface visual (UI)
Sensação de produto real
Consistência visual
